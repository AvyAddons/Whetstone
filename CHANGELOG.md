# Whetstone Changelog

All notable changes to this project will be documented in this file. Be aware that the [Unreleased] features are not yet available in the official tagged builds.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this project adheres to [Semantic Versioning](http://semver.org/).

## [Unreleased]

## [0.6.0] - 2026-11-20

### Added

- Option to hide capped skills. Skills ready to train stay shown

## [0.5.0] - 2026-11-17

### Changed

- Settings are shared by every character on the account. A character can keep its own position, visibility, or skill list from the "This character" section of the options
- The first character you log in with after updating supplies the shared settings. Other characters keep their own position, visibility, and skill list where these differ from it

## [0.4.0] - 2026-11-06

### Added

- Bar width customisation

## [0.3.0] - 2026-10-31

### Added

- Support for TBC Anniversary

### Changed

- Internal API changes for Forever

## [0.2.0] - 2026-10-04

### Added

- Feral Combat weapon skill on WoW Forever, shown while in Bear or Cat form

## [0.1.0] - 2026-09-30

### Added

- Floating bar with a tile for every profession, secondary skill and weapon skill
- Alerts when a skill is capped or ready for the next rank
- Custom bar textures and fonts, with LibSharedMedia support
- WoW Forever support
